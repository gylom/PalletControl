Build limitation
----------------
The .NET SDK is not installed in this execution environment, so a real `dotnet build` cannot be run here.
An attempted npm dependency install timed out because external package retrieval is unavailable here, so a full Vite build also cannot be run in this environment.

Run on the Rider PC
-------------------
IMPORTANT: stop any old `dotnet run` process before testing. `dotnet build` does not replace code already loaded by a running backend process.

1. Stop the currently running backend (Ctrl+C in its terminal).
2. Replace/sync the v5.9.1 files.
3. From backend/PalletControl.Api:
   dotnet clean
   dotnet build
   dotnet run
4. In a browser or PowerShell verify:
   http://localhost:5000/api/version
   It must report 5.9.1.
5. From frontend:
   npm install
   npm run build
   npm run dev
6. Run the non-destructive smoke test from the project root:
   .\smoke-test.ps1

Expected SuperAdmin behavior
----------------------------
- Header `Active` selector switches the live operational context SRD / ARE / KRS.
- Admin `Manage terminal` selector independently chooses which terminal is being administered.
- Users, Vehicles, Drivers, Transporters, Terminal settings, Linehaul comments and Linehaul/Mottatt locations follow Manage terminal.
- System Health is global/SuperAdmin-only and does not depend on Manage terminal.
